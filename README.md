# 🎮 网页游戏仓库 (Web Games)

专门存放可玩的网页游戏，通过 **GitHub Pages** 静态页面在线游玩。

## 游戏列表

| 游戏 | 玩法 | 状态 |
|------|------|------|
| [打地鼠](whack-a-mole/game_mole.html) | 点击从洞里冒出的地鼠得分，避开炸弹，抢金地鼠 | ✅ 可玩 |

## 怎么玩

1. 进入游戏目录，打开 `game_mole.html`
2. 触屏点击或鼠标点击地鼠
3. 30 秒内尽可能多地打中地鼠（避开炸弹）

## 部署 (GitHub Pages)

本仓库通过 GitHub Pages 部署，访问 `https://<用户名>.github.io/<仓库名>/` 即可在线游玩。
