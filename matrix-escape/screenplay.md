# 经典电影桥段 FPS 剧本：《黑客帝国》走廊枪战

> 本文件是 task-2（构建游戏）与 task-3（验证通关）的**唯一依据**。所有分镜、波次、敌人、目标、台词、胜利条件均以此为准。

## 一、电影桥段来源

- **影片**：《黑客帝国》(The Matrix, 1999)，导演：莉莉·沃卓斯基 / 拉娜·沃卓斯基（Wachowski 姐妹）。
- **桥段**：尼奥（Neo）与崔妮蒂（Trinity）潜入"守护者大厦"（Government Building）后的大楼**走廊枪战**——进入大堂、清剿守卫、沿走廊推进、遭遇特工（Agent Smith 等）、最终撤离。
- **风格**：绿色代码雨背景、黑色风衣、慢动作子弹时间（bullet-time）、走廊两侧掩体（办公桌/柱子/箱子）、密集枪战与"万枪齐发"的火力展示。
- **改编定位**：1 分钟单人走廊 FPS（第一人称），复刻"出生 → 遭遇波次 → 头目 → 出口"的节奏。

## 二、1 分钟时间线（0–60s）

| 时间段 | 阶段 | 目标 | 敌人 | 触发/判定 |
|---|---|---|---|---|
| 0–5s | **出生** | 玩家出现在走廊入口，向前推进（W = 相机前方） | 无 | `player.ready` 后开始计时 |
| 5–20s | **波次 1：保安** | 清剿走廊第一批守卫（4 名，掩体后） | 保安（Guard） | 全灭后进入波次 2 |
| 20–35s | **波次 2：特勤** | 清剿第二批特勤队员（4 名，更多掩体、更强） | 特勤（SWAT） | 全灭后触发头目 |
| 35–50s | **头目：特工史密斯** | 击败特工史密斯（高血量、主动压进） | 特工史密斯（Boss） | 头目死亡 → 出口门开 |
| 50–60s | **出口** | 抵达走廊尽头出口门（绿色门 / 撤离点） | 无 | 进入出口半径 → 胜利 |

> 时间线为**目标时长**（约 60s 内通关）；若玩家更快击杀，阶段可提前衔接（不强制等待），总时长仍须 ≤ 60s。

## 三、每段目标详解

1. **出生（0–5s）**：玩家出生在走廊一端，面向走廊深处。第一人称视角，手持步枪。目标：按住 W 向前推进，进入交火区。
2. **波次 1（5–20s）**：4 名保安在走廊中段掩体（木箱/办公桌）后。目标：全部击杀。可依托掩体（箱/桌/柱）躲避并反击。
3. **波次 2（20–35s）**：4 名特勤在走廊后段掩体（混凝土矮墙/铁桶）后，射击更准、血量更高。目标：全部击杀。特勤会在掩体间推进。
4. **头目（35–50s）**：特工史密斯从走廊尽头现身，黑色西装、墨镜，高血量、中速压进、连续开火。目标：将其击败。头目死亡时播放慢动作/子弹时间表现（如有）。
5. **出口（50–60s）**：头目死亡后，走廊尽头绿色出口门开启（发光标记）。目标：走进出口门（触发半径 ~1.2m）→ 胜利。

## 四、敌人类型（敌人系统）

| 类型 | 模型/外观 | 血量 | 武器 | 行为 | 数量 |
|---|---|---|---|---|---|
| 保安 Guard | 灰西装/保安制服，持手枪 | 低（2 发击杀） | 手枪（低频、低伤） | 站桩/小位移，掩体后射击 | 4 |
| 特勤 SWAT | 深色战术服/防弹背心，持步枪 | 中（4–5 发击杀） | 步枪（中频、中伤） | 掩体间推进，向玩家压进 | 4 |
| 特工史密斯 Boss | 黑西装+墨镜（特工造型），体量大 | 高（约 20–25 发击杀） | 连续点射（高频、中高伤） | 主动压进、周期性停顿射击 | 1 |

> 敌人复用 `devkit/fps` 的 enemy 系统与模型（`models/enemy`、`models/crate`、`models/barrel`、`models/wall`、`models/cover`、`models/ground`、`models/muzzle`）。头目可在 enemy 模型基础上放大/换色（黑西装+墨镜）表示。

## 六、胜利条件

1. **通关目标**：在 **60 秒内**完成 出生 → 清剿波次 1（4 保安）→ 清剿波次 2（4 特勤）→ 击败头目（特工史密斯）→ 抵达出口门。
2. **失败条件**：玩家血量归零（死亡），或超时（>60s 未到出口）。失败可重试（重置到出生点）。
3. **判定**：`victory = 出口触发半径内 && 头目已死 && 波次1/2全灭`。
4. **输出**：通关时显示"任务完成/逃离成功"画面并记录耗时；供 task-3 验证（确认 ≤60s 通关）。

## 七、场景/关卡要求（供 task-2 构建）

- **关卡结构**：直线/略带转角的走廊（约 40–60m），两侧掩体（木箱、办公桌、混凝土矮墙、铁桶、柱子），走廊尽头绿色出口门。
- **环境**：绿色调、网格地面、墙体（`models/wall`），可复用 `devkit/fps` 的 models/textures。
- **玩家**：第一人称，步枪（`models/rifle`）+ 手枪（`models/pistol`，副武器），射击/换弹/掩体；移动由 WASD + 鼠标（自由视角）。
- **电影化表现**（可复用 `battle_cine.js`）：开场运镜（走廊推进）、击杀慢动作/子弹时间、头目登场镜头、出口镜头。
- **音效/BGM**：`bgm.m4a`（战斗 BGM），射击/命中/击杀音效（复用 devkit 音效）。
- **渲染优化**（task-3 流畅性）：`antialias:false`、`setPixelRatio(1)`、`PCFShadowMap`（参照 `short_drama/output/game/index.html` 的做法）。
