🎯 设计方向（基于热门趋势）

  • 室外战区：从矩阵走廊破门而出

  • 撤离模式：击败守卫 → 开启撤离点

  • 掩体推进 + 战术走位

🔧 技术规格

场景元素

  • 地面：ground.glb（废墟质感）
  • 掩体：cover.glb / crate.glb / barrel.glb
  • 新元素：集装箱（程序化 Box）
  • 灯光：月光 Directional + 信号弹 Point

玩法机制

  • 波次导演：沿用 DIR 状态机
  • 撤离点：直升机 + 地面光圈
  • 限时 90s（延长）
  • 胜利：抵达撤离光圈

性能

  • 复用现有 glb 模型
  • 程序化几何体（低多边形）
  • PCF 阴影 256px
  • 保持 60fps 自适应
📌 设计说明：本关是上一关（矩阵走廊）的续章 —— 玩家从矩阵系统"苏醒"逃出，进入室外战区，采用热门游戏的撤离（Extraction）玩法。场景为通用军事废墟设计（不复制任何版权游戏元素），需你确认设计方向后再接入游戏代码。
